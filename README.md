# Gestão Coco Bambu — Falhas Operacionais

Aplicação web inicial para registrar, analisar e acompanhar falhas operacionais, prejuízos, reincidências, planos de ação e reuniões de ajuste.

## Primeira versão
- Central da Semana
- Ocorrências
- Planos de Ação
- Reuniões de Ajuste
- Análises e Relatórios
- Layout responsivo claro
- Dados demonstrativos locais
- Cadastro manual provisório de ocorrência
- Criação de planos de ação em memória

## Próximas etapas
1. Persistência em banco de dados.
2. Autenticação e perfis.
3. Integração com bot do Telegram.
4. Upload/armazenamento das fotos originais.
5. Classificação automática e detecção de reincidências.

Abra `index.html` para visualizar localmente.
